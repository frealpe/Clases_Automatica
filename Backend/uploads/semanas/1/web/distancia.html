Material complementario: soluciones de ejercicios-distancia.tex. Útil como repaso de geometría analítica aplicada antes de entrar de lleno a sistemas de ecuaciones, y como puente hacia el Ejercicio 7, que combina ambos temas.

Fórmula general La distancia \(d\) desde un punto \(P(x_1, y_1)\) a una recta \(L\) dada por la ecuación general \(Ax + By + C = 0\) se define como: \[ d = \frac{|Ax_1 + By_1 + C|}{\sqrt{A^2 + B^2}} \]
1Distancia entre \(2x - 3y = 4\) y el punto \((-7, -2)\).

Forma general: \(2x - 3y - 4 = 0\), con \(A=2, B=-3, C=-4\).

\[ d = \frac{|2(-7) - 3(-2) - 4|}{\sqrt{2^2 + (-3)^2}} = \frac{|-12|}{\sqrt{13}} = \frac{12\sqrt{13}}{13} \]
2Distancia entre \(-5x + 6y = 2\) y el punto \((1, 3)\).

Forma general: \(-5x + 6y - 2 = 0\), con \(A=-5, B=6, C=-2\).

\[ d = \frac{|-5(1) + 6(3) - 2|}{\sqrt{(-5)^2 + 6^2}} = \frac{|11|}{\sqrt{61}} = \frac{11\sqrt{61}}{61} \]
3Distancia entre \(2x - 4y = -42\) y el punto \((7, -21)\).

Forma general: \(2x - 4y + 42 = 0\), con \(A=2, B=-4, C=42\).

\[ d = \frac{|2(7) - 4(-21) + 42|}{\sqrt{2^2 + (-4)^2}} = \frac{|140|}{\sqrt{20}} = 14\sqrt{5} \]
4Distancia entre \(7x + 5y = 6\) y el punto \((0, 0)\).

Forma general: \(7x + 5y - 6 = 0\), con \(A=7, B=5, C=-6\).

\[ d = \frac{|7(0) + 5(0) - 6|}{\sqrt{7^2 + 5^2}} = \frac{6}{\sqrt{74}} = \frac{3\sqrt{74}}{37} \]
5Distancia entre \(3x + 7y = 0\) y el punto \((-2, -8)\).

Ya en forma general: \(3x + 7y + 0 = 0\), con \(A=3, B=7, C=0\).

\[ d = \frac{|3(-2) + 7(-8)|}{\sqrt{3^2 + 7^2}} = \frac{|-62|}{\sqrt{58}} = \frac{31\sqrt{58}}{29} \]
6Distancia entre \(11x - 12y = 5\) y el punto \((0, 4)\).

Forma general: \(11x - 12y - 5 = 0\), con \(A=11, B=-12, C=-5\).

\[ d = \frac{|11(0) - 12(4) - 5|}{\sqrt{11^2 + (-12)^2}} = \frac{|-53|}{\sqrt{265}} = \frac{53\sqrt{265}}{265} \]
7Distancia entre la recta \(2x - y = 6\) y el punto de intersección de \(3x - 2y = 1\) y \(6x + 3y = 32\).

Paso 1 — hallar el punto de intersección (un sistema 2×2, como en la sección 1.2): multiplicamos la primera ecuación por \(-2\) y sumamos con la segunda:

\[ (-6x + 4y) + (6x + 3y) = -2 + 32 \implies 7y = 30 \implies y = \tfrac{30}{7} \] \[ 3x - 2\left(\tfrac{30}{7}\right) = 1 \implies x = \tfrac{67}{21} \]

Punto de intersección: \(P\left(\tfrac{67}{21}, \tfrac{30}{7}\right)\).

Paso 2 — distancia de \(P\) a \(2x - y - 6 = 0\) (\(A=2, B=-1, C=-6\)):

\[ d = \frac{\left|2\left(\tfrac{67}{21}\right) - \tfrac{30}{7} - 6\right|}{\sqrt{2^2 + (-1)^2}} = \frac{\left|-\tfrac{82}{21}\right|}{\sqrt{5}} = \frac{82\sqrt{5}}{105} \]
