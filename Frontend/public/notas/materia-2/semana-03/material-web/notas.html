1. Funciones: qué son y por qué modularizar

Definición — Función Una función es un bloque de código con nombre propio que realiza una tarea específica, puede recibir datos de entrada (parámetros) y puede devolver un resultado (valor de retorno). Una vez definida, se puede llamar (invocar) tantas veces como se necesite desde cualquier parte del programa.
Definición — Diseño descendente / modularización El diseño descendente (top-down) consiste en dividir un problema grande en subproblemas más pequeños y manejables, y resolver cada uno con su propia función. El programa principal (main) queda como una secuencia corta de llamadas a funciones, cada una responsable de una sola tarea bien definida.
Propiedad — Ventajas de modularizar
  • Reutilización: una función escrita una vez se puede llamar muchas veces, en el mismo programa o en otros.
  • Legibilidad: un main de 5 llamadas a funciones bien nombradas se entiende más rápido que 200 líneas seguidas.
  • Mantenibilidad: si hay que corregir cómo se calcula algo, se corrige en un solo lugar (dentro de la función), no en cada copia del cálculo.
  • Prueba independiente: cada función se puede probar por separado antes de integrar el programa completo.

2. Declaración, definición y prototipo de una función

Definición — Prototipo de función El prototipo anuncia al compilador que una función existe, cuál es su nombre, qué tipo de dato retorna y qué parámetros recibe (con sus tipos), sin incluir el cuerpo: 
tipo_retorno nombre_funcion(tipo1 param1, tipo2 param2, ...);
Se coloca antes de main (o en un archivo de cabecera) cuando la función se define después de donde se llama.
Definición — Definición de función La definición incluye el cuerpo completo: las instrucciones que la función ejecuta, y la instrucción return que devuelve el resultado (si la función no es void).
Ejemplo — Función con retorno 
#include <stdio.h>

double areaCirculo(double radio);   // prototipo

int main(void) {
    double r = 3.0;
    double area = areaCirculo(r);   // llamada
    printf("Area = %.2f\n", area);
    return 0;
}

double areaCirculo(double radio) {  // definicion
    return 3.14159 * radio * radio;
}
main llama a areaCirculo(r): el valor de r se copia en el parámetro radio, la función calcula y devuelve el área con return, y ese valor queda disponible en main dentro de la variable area.
Definición — Función void Una función declarada con tipo de retorno void no devuelve ningún valor: se usa cuando la tarea de la función es hacer algo (por ejemplo, imprimir) en vez de calcular algo. No lleva return valor; (a lo sumo un return; vacío para salir antes de tiempo).
Ejemplo — Función void 
#include <stdio.h>

void imprimirTabla(int n);

int main(void) {
    imprimirTabla(5);
    return 0;
}

void imprimirTabla(int n) {
    for (int i = 1; i <= 10; i++) {
        printf("%d x %d = %d\n", n, i, n * i);
    }
}

3. Paso de parámetros por valor

Propiedad — Paso por valor En C, cuando se llama a una función, cada parámetro recibe una copia del valor del argumento pasado. La función trabaja sobre esa copia: cualquier cambio que haga al parámetro dentro de su cuerpo no se refleja en la variable original del código que hizo la llamada.
Ejemplo — El paso por valor no modifica el original 
#include <stdio.h>

void incrementar(int x) {
    x = x + 1;              // modifica solo la copia local x
    printf("Dentro de incrementar: x = %d\n", x);
}

int main(void) {
    int numero = 5;
    incrementar(numero);
    printf("Despues de incrementar: numero = %d\n", numero);
    return 0;
}
SalidaDentro de incrementar: x = 6, seguido de Despues de incrementar: numero = 5. numero no cambió, porque x es una copia independiente que vive solo mientras se ejecuta incrementar. Para que una función SÍ pueda modificar una variable del llamador hace falta pasarle su dirección de memoria (un puntero) — tema de la Semana 14.

4. Ámbito de las variables: locales y globales

Definición — Variable local Una variable declarada dentro de una función (incluidos sus parámetros) es local a esa función: solo existe y es visible mientras la función se está ejecutando, y desaparece al terminar. Dos funciones distintas pueden tener variables locales con el mismo nombre sin interferir entre sí.
Definición — Variable global Una variable declarada fuera de todas las funciones (normalmente al inicio del archivo) es global: existe durante toda la ejecución del programa y es visible desde cualquier función definida después de ella.
Ejemplo — Variable global compartida entre funciones 
#include <stdio.h>

int contadorEventos = 0;   // variable global

void registrarEvento(void) {
    contadorEventos++;     // modifica la variable global directamente
}

int main(void) {
    registrarEvento();
    registrarEvento();
    registrarEvento();
    printf("Eventos registrados: %d\n", contadorEventos);   // imprime 3
    return 0;
}
A diferencia de un parámetro, una variable global no se copia: todas las funciones que la usan leen y escriben la misma variable.
Propiedad — Usar variables globales con cuidado Abusar de variables globales dificulta entender y depurar un programa, porque cualquier función puede cambiarlas en cualquier momento (efectos ocultos). La práctica recomendada es preferir variables locales y comunicar datos entre funciones explícitamente, por parámetros y valores de retorno; reservar las variables globales para casos claramente justificados (como un contador de eventos que de verdad debe compartirse entre muchas funciones).

5. Ejercicios propuestos y soluciones

1Escribe una función double areaCirculo(double radio) que calcule y retorne el área de un círculo, y un main que la use para un radio leído por teclado. 
#include <stdio.h>

double areaCirculo(double radio);

int main(void) {
    double r;
    printf("Ingrese el radio: ");
    scanf("%lf", &r);
    printf("Area = %.2f\n", areaCirculo(r));
    return 0;
}

double areaCirculo(double radio) {
    return 3.14159 * radio * radio;
}
2Escribe una función int esPar(int n) que retorne 1 si n es par y 0 si es impar, y úsala en un ciclo para clasificar los números del 1 al 10. 
#include <stdio.h>

int esPar(int n);

int main(void) {
    for (int i = 1; i <= 10; i++) {
        if (esPar(i)) {
            printf("%d es par\n", i);
        } else {
            printf("%d es impar\n", i);
        }
    }
    return 0;
}

int esPar(int n) {
    return (n % 2 == 0) ? 1 : 0;
}
3Escribe una función void imprimirTabla(int n) (sin retorno) que imprima la tabla de multiplicar de n del 1 al 10. 
#include <stdio.h>

void imprimirTabla(int n);

int main(void) {
    int n;
    printf("Ingrese un numero: ");
    scanf("%d", &n);
    imprimirTabla(n);
    return 0;
}

void imprimirTabla(int n) {
    for (int i = 1; i <= 10; i++) {
        printf("%d x %d = %d\n", n, i, n * i);
    }
}
4Escribe una función int maximo(int a, int b, int c) que retorne el mayor de tres números enteros. 
#include <stdio.h>

int maximo(int a, int b, int c);

int main(void) {
    printf("El mayor es %d\n", maximo(7, 15, 3));
    return 0;
}

int maximo(int a, int b, int c) {
    int m = a;
    if (b > m) m = b;
    if (c > m) m = c;
    return m;
}
5Escribe un programa con una variable global contadorEventos y una función void registrarEvento(void) que la incremente; llama a la función 5 veces desde main e imprime el total al final. 
#include <stdio.h>

int contadorEventos = 0;

void registrarEvento(void);

int main(void) {
    for (int i = 0; i < 5; i++) {
        registrarEvento();
    }
    printf("Eventos registrados: %d\n", contadorEventos);
    return 0;
}

void registrarEvento(void) {
    contadorEventos++;
}
SalidaImprime Eventos registrados: 5.
6Dado el código void incrementar(int x) { x = x + 1; }, llamado como int numero = 10; incrementar(numero);, explica por qué numero sigue valiendo 10 después de la llamada.
SoluciónEn C, los parámetros se pasan por valor: al llamar a incrementar(numero), el parámetro x recibe una copia del valor de numero (10). Dentro de la función, x = x + 1 modifica esa copia local (x pasa a valer 11), pero numero, la variable original en main, es una variable distinta en otra región de memoria y no se ve afectada. Al terminar la función, la copia x desaparece y numero sigue valiendo 10.
