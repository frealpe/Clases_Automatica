1. Estructuras condicionales: if, if-else, else if, operador ternario

Definición — Sentencia condicional Una sentencia condicional ejecuta un bloque de código solo si una expresión —la condición— es verdadera. En C, cualquier valor distinto de 0 se considera verdadero, y 0 se considera falso.
Ejemplo — if simple y if-else 
int numero = -5;

if (numero >= 0) {
    printf("El numero es positivo o cero\n");
} else {
    printf("El numero es negativo\n");
}
Si la condición numero >= 0 es falsa, se ejecuta el bloque else. El bloque else es opcional.
Ejemplo — else if encadenado 
float nota = 3.2f;

if (nota >= 4.5f) {
    printf("Excelente\n");
} else if (nota >= 3.0f) {
    printf("Aprobado\n");
} else {
    printf("Reprobado\n");
}
Las condiciones se evalúan en orden; se ejecuta el primer bloque cuya condición sea verdadera, y se ignoran las siguientes.
Definición — Operador ternario La expresión condicion ? valor_si_verdadero : valor_si_falso es una forma compacta de un if-else que produce un valor, útil para asignaciones simples.
Ejemplo — Operador ternario 
int a = 8, b = 3, mayor;
mayor = (a > b) ? a : b;
printf("El mayor es %d\n", mayor);   // imprime 8
Propiedad — Condiciones compuestas Los operadores lógicos && (y), || (o) y ! (no) combinan varias condiciones relacionales en una sola expresión. C evalúa && y || de izquierda a derecha y se detiene apenas el resultado queda determinado (cortocircuito): en a && b, si a es falso, b ni siquiera se evalúa.
Ejemplo — Condición compuesta 
int edad = 20;
int tiene_carnet = 1;   // 1 = verdadero, 0 = falso

if (edad >= 18 && tiene_carnet) {
    printf("Puede ingresar\n");
} else {
    printf("No puede ingresar\n");
}
Ejemplo — Clasificador con varias condiciones compuestas Cuando hay más de dos posibles resultados, se encadenan varios if/else if, cada uno con su propia condición compuesta, evaluados en orden de más a menos restrictivo: 
int tiene_sensor, tiene_actuador, conectado;
float bateria;   // porcentaje, 0.0 a 100.0

printf("Tiene sensor (1/0): ");
scanf("%d", &tiene_sensor);
printf("Tiene actuador (1/0): ");
scanf("%d", &tiene_actuador);
printf("Nivel de bateria: ");
scanf("%f", &bateria);
printf("Conectado a la red (1/0): ");
scanf("%d", &conectado);

if (tiene_sensor && tiene_actuador && bateria > 50 && conectado) {
    printf("Dispositivo IoT avanzado\n");
} else if (tiene_sensor && bateria >= 20 && conectado) {
    printf("Dispositivo IoT basico\n");
} else if ((tiene_sensor || tiene_actuador) && !conectado) {
    printf("Dispositivo sin conexion\n");
} else if (bateria < 10) {
    printf("Bateria critica\n");
} else {
    printf("Dispositivo no clasificado\n");
}
Cada rama se evalúa solo si todas las anteriores fueron falsas; por eso el orden importa: la condición más específica (avanzado) va primero, y la más general (else final) queda de respaldo para cualquier combinación no prevista.

2. La instrucción switch-case

Definición — switch-case switch compara el valor de una expresión entera (o char) contra una lista de casos (case), y ejecuta el bloque del primer caso que coincide. Sin un break al final de cada caso, la ejecución cae al siguiente caso (fall-through). default es opcional y se ejecuta si ningún caso coincide.
Ejemplo — Menú con switch 
int opcion = 2;
float a = 10, b = 4, resultado;

switch (opcion) {
    case 1:
        resultado = a + b;
        printf("Suma = %.2f\n", resultado);
        break;
    case 2:
        resultado = a - b;
        printf("Resta = %.2f\n", resultado);
        break;
    case 3:
        resultado = a * b;
        printf("Producto = %.2f\n", resultado);
        break;
    default:
        printf("Opcion invalida\n");
}
Con opcion = 2, se ejecuta el caso 2 e imprime Resta = 6.00; el break evita que también se ejecute el caso 3.

3. Ciclos: while, do-while, for

Definición — Ciclo o bucle Un ciclo repite un bloque de instrucciones mientras se cumpla una condición. C ofrece tres formas, que son intercambiables pero cada una es más natural según el problema.
Propiedad — while: condición al inicio 
int contador = 1;
while (contador <= 5) {
    printf("%d\n", contador);
    contador++;
}
La condición se evalúa antes de cada repetición; si es falsa desde el principio, el cuerpo no se ejecuta ni una vez. Útil cuando no se sabe de antemano cuántas repeticiones habrá (por ejemplo, leer datos hasta que el usuario ingrese un centinela).
Propiedad — do-while: condición al final 
int opcion;
do {
    printf("Ingrese una opcion (1-3): ");
    scanf("%d", &opcion);
} while (opcion < 1 || opcion > 3);
El cuerpo se ejecuta al menos una vez, porque la condición se evalúa después. Es la estructura natural para validar una entrada: hay que pedirla al menos una vez antes de poder validarla.
Propiedad — for: conteo explícito 
for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
El for agrupa en un solo lugar la inicialización (i = 1), la condición (i <= 5) y el incremento (i++). Es la forma más natural cuando se conoce de antemano el número de repeticiones (o un rango claro).

4. break, continue y anidamiento

Definición — break y continue break termina inmediatamente el ciclo (o el switch) que lo contiene. continue salta el resto del cuerpo del ciclo actual y pasa directamente a evaluar la siguiente repetición.
Ejemplo — break y continue 
for (int i = 1; i <= 10; i++) {
    if (i == 7) {
        break;              // termina el ciclo al llegar a 7
    }
    if (i % 2 == 0) {
        continue;           // salta los pares, no los imprime
    }
    printf("%d\n", i);      // imprime 1, 3, 5
}
Definición — Ciclos anidados Un ciclo anidado es un ciclo dentro de otro. Por cada repetición del ciclo externo, el ciclo interno se ejecuta completo. Se usan, por ejemplo, para recorrer una tabla de dos dimensiones (fila por fila, y dentro de cada fila, columna por columna).
Ejemplo — Tabla de multiplicar con ciclos anidados 
for (int fila = 1; fila <= 5; fila++) {
    for (int col = 1; col <= 5; col++) {
        printf("%3d", fila * col);
    }
    printf("\n");
}
Por cada valor de fila (ciclo externo), el ciclo interno recorre col de 1 a 5 e imprime el producto; al terminar el ciclo interno, se imprime un salto de línea para pasar a la siguiente fila.

5. Ejercicios propuestos y soluciones

1Escribe un programa que lea un número entero e imprima si es positivo, negativo o cero. 
#include <stdio.h>

int main(void) {
    int n;
    printf("Ingrese un numero: ");
    scanf("%d", &n);

    if (n > 0) {
        printf("Es positivo\n");
    } else if (n < 0) {
        printf("Es negativo\n");
    } else {
        printf("Es cero\n");
    }
    return 0;
}
2Escribe un programa que lea una edad e imprima, con if-else if, si la persona es menor de edad (<18), adulto (18–59) o adulto mayor (≥60). 
#include <stdio.h>

int main(void) {
    int edad;
    printf("Ingrese la edad: ");
    scanf("%d", &edad);

    if (edad < 18) {
        printf("Menor de edad\n");
    } else if (edad < 60) {
        printf("Adulto\n");
    } else {
        printf("Adulto mayor\n");
    }
    return 0;
}
3Escribe una calculadora básica: lee dos números y un operador ('+', '-', '*' o '/') como char, y con switch imprime el resultado. 
#include <stdio.h>

int main(void) {
    float a, b, resultado;
    char operador;

    printf("Ingrese numero, operador, numero (ej: 4 + 2): ");
    scanf("%f %c %f", &a, &operador, &b);

    switch (operador) {
        case '+':
            resultado = a + b;
            break;
        case '-':
            resultado = a - b;
            break;
        case '*':
            resultado = a * b;
            break;
        case '/':
            if (b == 0) {
                printf("Error: division por cero\n");
                return 1;
            }
            resultado = a / b;
            break;
        default:
            printf("Operador invalido\n");
            return 1;
    }
    printf("Resultado = %.2f\n", resultado);
    return 0;
}
4Escribe un programa que imprima los números del 1 al 20: primero usando for, y luego usando while. 
#include <stdio.h>

int main(void) {
    printf("Con for:\n");
    for (int i = 1; i <= 20; i++) {
        printf("%d ", i);
    }
    printf("\n");

    printf("Con while:\n");
    int i = 1;
    while (i <= 20) {
        printf("%d ", i);
        i++;
    }
    printf("\n");
    return 0;
}
5Escribe un programa que lea un entero n y calcule su factorial (n!) usando un ciclo. 
#include <stdio.h>

int main(void) {
    int n;
    long factorial = 1;

    printf("Ingrese n: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        factorial *= i;
    }
    printf("%d! = %ld\n", n, factorial);
    return 0;
}
NotaCon n=5: factorial = 1·2·3·4·5 = 120.
6Escribe un programa que lea un entero mayor que 1 y determine, usando un ciclo, si es primo. 
#include <stdio.h>

int main(void) {
    int n, es_primo = 1;

    printf("Ingrese un numero mayor que 1: ");
    scanf("%d", &n);

    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            es_primo = 0;
            break;          // ya encontramos un divisor, no hace falta seguir
        }
    }

    if (es_primo) {
        printf("%d es primo\n", n);
    } else {
        printf("%d no es primo\n", n);
    }
    return 0;
}
NotaEn cuanto se encuentra un divisor de n distinto de 1 y de sí mismo, break corta el ciclo: no hace falta seguir probando.
7Escribe un programa que imprima la tabla de multiplicar del 1 al 10 usando dos ciclos for anidados. 
#include <stdio.h>

int main(void) {
    for (int fila = 1; fila <= 10; fila++) {
        for (int col = 1; col <= 10; col++) {
            printf("%4d", fila * col);
        }
        printf("\n");
    }
    return 0;
}
8Usando do-while, lee números enteros y súmalos hasta que el usuario ingrese un 0 (el 0 no se suma), e imprime el total al final. 
#include <stdio.h>

int main(void) {
    int numero, suma = 0;

    do {
        printf("Ingrese un numero (0 para terminar): ");
        scanf("%d", &numero);
        if (numero != 0) {
            suma += numero;
        }
    } while (numero != 0);

    printf("Suma total = %d\n", suma);
    return 0;
}
NotaSe usa do-while porque hay que pedir el primer número antes de poder evaluar si es el centinela (0) que termina el ciclo.
