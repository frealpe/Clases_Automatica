1. ¿Qué es programar? Algoritmos y lenguajes

Definición — Algoritmo Un algoritmo es una secuencia finita, ordenada y no ambigua de pasos que resuelve un problema o realiza una tarea. Antes de escribir código, todo programa es —o debería ser— un algoritmo claro: qué datos entran, qué pasos se aplican, qué datos salen.
Definición — Programa y lenguaje de programación Un programa es la traducción de un algoritmo a un lenguaje que un computador puede ejecutar. Un lenguaje de programación es el conjunto de reglas (sintaxis) y significados (semántica) que permiten escribir esa traducción de forma no ambigua.
Propiedad — Compilados vs. interpretados En un lenguaje compilado (como C), un programa —el compilador— traduce todo el código fuente a instrucciones de máquina antes de ejecutarlo, generando un archivo ejecutable. En un lenguaje interpretado (como Python), otro programa —el intérprete— lee y ejecuta el código fuente línea a línea, sin generar un ejecutable independiente. C, al compilarse a código de máquina nativo, produce programas muy eficientes en tiempo y memoria: por eso es el lenguaje base de sistemas embebidos y de control.

2. El proceso de compilación en C y estructura de un programa

Propiedad — Del código fuente al ejecutable Compilar un programa en C con gcc pasa por cuatro etapas:
  1. Preprocesador: procesa las directivas que empiezan por # (como #include, #define), sustituyéndolas antes de compilar.
  2. Compilador: traduce el código fuente (ya preprocesado) a código ensamblador.
  3. Ensamblador: traduce el código ensamblador a código objeto (binario, aún no enlazado).
  4. Enlazador (linker): combina el código objeto con las librerías necesarias (como la librería estándar, que aporta printf) para producir el ejecutable final.
En la práctica, gcc programa.c -o programa ejecuta las cuatro etapas de un solo paso.
Definición — Estructura mínima de un programa en C Todo programa en C ejecutable necesita, como mínimo, una función main, que es el punto de entrada: la primera función que se ejecuta al correr el programa.
Ejemplo — Hola mundo 
#include <stdio.h>   // preprocesador: incluye la libreria estandar de E/S

int main(void) {
    printf("Hola, mundo\n");   // sentencia: termina en punto y coma
    return 0;                  // 0 indica que el programa termino sin errores
}
#include <stdio.h> le pide al preprocesador que incluya las declaraciones necesarias para usar printf. int main(void) declara la función principal, que devuelve un entero (int) al sistema operativo. El cuerpo de la función va entre llaves { }, y cada sentencia termina en punto y coma ;. El texto tras // es un comentario: el compilador lo ignora.

3. Tipos de datos, variables y constantes

Definición — Variable Una variable es un espacio de memoria con un nombre, un tipo de dato y un valor que puede cambiar durante la ejecución del programa. Debe declararse (indicar su tipo y nombre) antes de usarse, y puede inicializarse (darle un valor inicial) en la misma declaración.

Ejemplo — Rangos reales del compilador con limits.h, float.h y stdbool.h Los valores exactos de rango dependen del compilador; las cabeceras limits.h y float.h definen constantes (INT_MAX, DBL_MIN, etc.) que permiten consultarlos en tiempo de compilación, en vez de memorizarlos: 
#include <stdio.h>
#include <limits.h>   // INT_MAX, LONG_MIN, etc.
#include <float.h>    // FLT_MAX, DBL_MIN, etc.
#include <stdbool.h>  // bool, true, false (desde C99)

int main(void) {
    printf("int:   %zu bytes, de %d a %d\n", sizeof(int), INT_MIN, INT_MAX);
    printf("long:  %zu bytes, de %ld a %ld\n", sizeof(long), LONG_MIN, LONG_MAX);
    printf("float: %zu bytes, maximo %.10e\n", sizeof(float), FLT_MAX);

    bool activo = true;
    printf("bool:  %zu bytes, valor actual %d\n", sizeof(bool), activo);
    return 0;
}
stdbool.h no crea un tipo nuevo en el lenguaje: bool es una macro para _Bool, y true/false son macros para 1/0.

Definición — Constantes Una constante es un valor que no cambia durante la ejecución. En C se define de dos formas: con la directiva de preprocesador #define NOMBRE valor (sustitución de texto, sin tipo), o con el calificador const sobre una variable (const float PI = 3.1416;, con tipo y verificado por el compilador).
Definición — Macro Una macro es un #define más general: además de dar nombre a un valor, puede recibir parámetros. El preprocesador sustituye cada llamada a la macro por su definición textual, parámetro por parámetro, antes de que el compilador vea el código. A diferencia de una función, la sustitución no implica una llamada real en tiempo de ejecución.
Ejemplo — Macro con parámetros: empaquetar 8 bits en un entero La macro siguiente recibe 8 valores (cada uno 0 o 1) y los combina en un solo entero de 8 bits usando desplazamiento (<<) y OR bit a bit (|): 
#define BIN8(b7,b6,b5,b4,b3,b2,b1,b0) \
    (((b7)<<7) | ((b6)<<6) | ((b5)<<5) | ((b4)<<4) | \
     ((b3)<<3) | ((b2)<<2) | ((b1)<<1) | ((b0)<<0))

int main(void) {
    int a = BIN8(1,1,0,0,1,0,1,0);  // 0b11001010 = 202
    printf("%d\n", a);
    return 0;
}
Cada bit bN se desplaza N posiciones a la izquierda (b7<<7 lo deja en la posición más significativa) y luego se combinan todos con |, que en cada posición da 1 si al menos uno de los operandos tiene 1 ahí. Como cada bit ocupa una posición distinta, el OR simplemente los reúne sin que se pisen entre sí: el resultado es el número de 8 bits b7 b6 b5 b4 b3 b2 b1 b0 leído de izquierda a derecha. La barra \ al final de línea le dice al preprocesador que la definición continúa en la línea siguiente.
Propiedad — Reglas para nombres de variables Un identificador en C empieza por una letra o guion bajo (_), seguido de letras, dígitos o guiones bajos; distingue mayúsculas de minúsculas (Edad ≠ edad); y no puede coincidir con una palabra reservada del lenguaje (int, return, if, etc.).

4. Operadores

Propiedad — Familias de operadores
  • Aritméticos: + - * / % (% es el residuo de la división entera; / entre dos int trunca el resultado).
  • Relacionales: == != < > <= >=, resultan en 0 (falso) o 1 (verdadero).
  • Lógicos: && (y), || (o), ! (no), combinan condiciones.
  • Asignación: =, y las compuestas += -= *= /= %=.
  • Incremento/decremento: ++ y -- (prefijo o sufijo).
Ejemplo — División entera vs. residuo 
int a = 7, b = 2;
printf("%d\n", a / b);   // imprime 3 (division entera, se trunca)
printf("%d\n", a % b);   // imprime 1 (residuo de 7 entre 2)
printf("%f\n", (float)a / b);   // imprime 3.500000 (conversion explicita)

5. Entrada y salida estándar

Propiedad — printf y scanf printf escribe en la consola una cadena de formato donde cada especificador (%d entero, %f flotante, %lf double con scanf, %c carácter, %s cadena) se sustituye por el valor del argumento correspondiente. scanf lee de teclado hacia variables, y necesita el operador & (dirección de memoria) delante de cada variable —excepto para cadenas (char[]), donde el nombre del arreglo ya es una dirección.
Ejemplo — Programa integrador: área de un círculo 
#include <stdio.h>

int main(void) {
    const float PI = 3.14159f;
    float radio, area;

    printf("Radio del circulo: ");
    scanf("%f", &radio);

    area = PI * radio * radio;
    printf("Area = %.2f\n", area);

    return 0;
}

6. Ejercicios propuestos y soluciones

1Escribe un programa que imprima tu nombre y el nombre de la asignatura en dos líneas separadas, usando dos sentencias printf. 
#include <stdio.h>

int main(void) {
    printf("Mi nombre es Ana Torres\n");
    printf("Asignatura: Programacion\n");
    return 0;
}
2Declara variables float base y altura para un triángulo, asígnales valores, calcula el área (base×altura/2) e imprímela con dos decimales. 
#include <stdio.h>

int main(void) {
    float base = 6.0f, altura = 4.5f, area;
    area = base * altura / 2;
    printf("Area del triangulo = %.2f\n", area);
    return 0;
}
NotaCon base = 6.0 y altura = 4.5, el área es 6.0 × 4.5 / 2 = 13.50.
3El siguiente código tiene tres errores de sintaxis. Identifícalos y corrígelos: 
#include <stdio.h>

int main(void)
    int x = 5
    printf("x vale %d\n", x);
    return 0;
}
SoluciónLos tres errores: (i) falta el paréntesis de apertura { después de int main(void); (ii) falta el punto y coma al final de int x = 5; (iii) sobra la llave de cierre } final porque nunca se abrió la primera. Versión corregida:
#include <stdio.h>

int main(void) {
    int x = 5;
    printf("x vale %d\n", x);
    return 0;
}
4Declara una variable char letra = 'A'; e imprime su valor con %c y su código ASCII con %d. 
#include <stdio.h>

int main(void) {
    char letra = 'A';
    printf("Caracter: %c\n", letra);
    printf("Codigo ASCII: %d\n", letra);
    return 0;
}
SalidaCaracter: A y Codigo ASCII: 65, porque el código ASCII de 'A' es 65.
5Escribe un programa que lea dos enteros con scanf y muestre su suma, resta, producto, cociente entero y residuo. 
#include <stdio.h>

int main(void) {
    int a, b;
    printf("Ingrese dos enteros: ");
    scanf("%d %d", &a, &b);

    printf("Suma = %d\n", a + b);
    printf("Resta = %d\n", a - b);
    printf("Producto = %d\n", a * b);
    printf("Cociente entero = %d\n", a / b);
    printf("Residuo = %d\n", a % b);
    return 0;
}
6Usando sizeof, escribe un programa que imprima el tamaño en bytes de int, float, double y char. 
#include <stdio.h>

int main(void) {
    printf("int:    %lu bytes\n", sizeof(int));
    printf("float:  %lu bytes\n", sizeof(float));
    printf("double: %lu bytes\n", sizeof(double));
    printf("char:   %lu bytes\n", sizeof(char));
    return 0;
}
NotaEn la mayoría de compiladores actuales (arquitectura de 64 bits): int = 4, float = 4, double = 8, char = 1 byte.
