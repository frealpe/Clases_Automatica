Definición — Sistemas equivalentes Dos sistemas de ecuaciones lineales son equivalentes si tienen exactamente el mismo conjunto de soluciones. Que dos sistemas sean equivalentes no significa que sean iguales: pueden tener ecuaciones distintas y, sin embargo, toda solución de uno ser solución del otro.
Teorema — Las operaciones elementales de fila producen sistemas equivalentes Cada una de las tres operaciones elementales de fila aplicada a la matriz aumentada \([A\mid\mathbf{b}]\) produce la matriz aumentada de un sistema equivalente al original:
  1. Intercambiar dos filas (equivale a reordenar ecuaciones).
  2. Multiplicar una fila por un escalar \(c\neq 0\) (equivale a multiplicar ambos lados de una ecuación por \(c\)).
  3. Sumar a una fila un múltiplo escalar de otra (equivale a reemplazar una ecuación por su suma con un múltiplo de otra).
Por tanto, el sistema obtenido al final del algoritmo de Gauss-Jordan tiene el mismo conjunto solución que el sistema original.

Justificación. Cada operación es reversible: se puede deshacer con otra operación del mismo tipo. Como cada paso preserva el conjunto solución y se puede volver al sistema anterior, los dos sistemas tienen exactamente las mismas soluciones, es decir, son equivalentes.

Definición — Sistema consistente e inconsistente
  • Un sistema es consistente si tiene al menos una solución (puede ser única o infinitas).
  • Un sistema es inconsistente si no tiene ninguna solución.
La inconsistencia se detecta en la forma escalonada: existe una fila del tipo \([\,0\;\cdots\;0\mid c\,]\) con \(c\neq 0\), que representa la ecuación \(0=c\), una contradicción.
Ejemplo — Detectar una inconsistencia El sistema \[ x_1 + x_2 = 3, \qquad 2x_1 + 2x_2 = 7 \] es inconsistente. Al reducir la matriz aumentada: \[ \left(\begin{array}{cc|c}1&1&3\\2&2&7\end{array}\right) \xrightarrow{F_2-2F_1} \left(\begin{array}{cc|c}1&1&3\\0&0&1\end{array}\right) \] La segunda fila dice \(0=1\): contradicción. El sistema no tiene solución.

Los tres casos posibles

Para cualquier número de ecuaciones e incógnitas, un sistema lineal siempre cae en exactamente uno de estos tres casos. Los siguientes tres ejemplos muestran cada caso de forma completa, reduciendo la matriz aumentada hasta su forma escalonada (o escalonada reducida).

Caso 1 — Sistema inconsistente \[ x_1 + x_2 = 3, \qquad 2x_1 + 2x_2 = 7. \] Reducción de la matriz aumentada: \[ \left(\begin{array}{cc|c}1&1&3\\2&2&7\end{array}\right) \xrightarrow{F_2 - 2F_1} \left(\begin{array}{cc|c}1&1&3\\0&0&1\end{array}\right). \] La fila \([0\ 0\mid 1]\) representa la ecuación \(0=1\): contradicción. El sistema es inconsistente; no tiene solución. (Geométricamente, las dos rectas son paralelas.)
Caso 2 — Solución única \[ x_1 + x_2 + x_3 = 6,\quad 2x_1 - x_2 + x_3 = 3,\quad x_1 + 2x_2 - x_3 = 2. \] Reducción completa (RREF): \[ \left(\begin{array}{ccc|c}1&1&1&6\\2&-1&1&3\\1&2&-1&2\end{array}\right) \xrightarrow{F_2-2F_1,\;F_3-F_1} \left(\begin{array}{ccc|c}1&1&1&6\\0&-3&-1&-9\\0&1&-2&-4\end{array}\right) \] \[ \xrightarrow{F_2\leftrightarrow F_3} \left(\begin{array}{ccc|c}1&1&1&6\\0&1&-2&-4\\0&-3&-1&-9\end{array}\right) \xrightarrow{F_3+3F_2} \left(\begin{array}{ccc|c}1&1&1&6\\0&1&-2&-4\\0&0&-7&-21\end{array}\right) \] \[ \xrightarrow{-\tfrac{1}{7}F_3} \left(\begin{array}{ccc|c}1&1&1&6\\0&1&-2&-4\\0&0&1&3\end{array}\right) \xrightarrow{\substack{F_2+2F_3\\F_1-F_3}} \left(\begin{array}{ccc|c}1&1&0&3\\0&1&0&2\\0&0&1&3\end{array}\right) \xrightarrow{F_1-F_2} \left(\begin{array}{ccc|c}1&0&0&1\\0&1&0&2\\0&0&1&3\end{array}\right). \] Rango \(r=3=n\): el sistema es consistente con solución única \[ x_1=1,\quad x_2=2,\quad x_3=3. \]
Solución única: \((x_1,x_2,x_3)=(1,2,3)\).
Caso 3 — Infinitas soluciones \[ x_1 + 2x_2 - x_3 = 0, \qquad 2x_1 + 4x_2 - 2x_3 = 0. \] (La segunda ecuación es el doble de la primera.) Reducción: \[ \left(\begin{array}{ccc|c}1&2&-1&0\\2&4&-2&0\end{array}\right) \xrightarrow{F_2-2F_1} \left(\begin{array}{ccc|c}1&2&-1&0\\0&0&0&0\end{array}\right). \] Rango \(r=1 < n=3\): hay \(n-r=2\) variables libres. Tomando \(x_2=s\) y \(x_3=t\) libres: \[ x_1 = -2s + t. \] El conjunto solución (familia de infinitas soluciones) es \[ \{(-2s+t,\;s,\;t)\mid s,t\in\mathbb{R}\}. \] El vector \((0,0,0)\) corresponde a \(s=t=0\); p. ej., \((1,0,1)\) se obtiene con \(s=0,\,t=1\).
Conjunto solución infinito, parametrizado por \(s\) y \(t\).
