2.5. Transpuesta de una Matriz y Simetría

Definición de Matriz Transpuesta $A^T$

Dada una matriz $A = (a_{ij})_{m\times n}$, su transpuesta $A^T = (a_{ji})_{n\times m}$ es la matriz obtenida al intercambiar sus filas por sus columnas:

$$(A^T)_{ij} = a_{ji}$$

Propiedades del Álgebra de Transposiciones

  • $(A^T)^T = A$
  • $(A + B)^T = A^T + B^T$
  • $(cA)^T = c A^T$
  • $(AB)^T = B^T A^T$ (¡el orden de los factores se invierte!)
  • $(A^T)^{-1} = (A^{-1})^T$ para cualquier matriz invertible $A$.

Matrices Simétricas y Antisimétricas

Para una matriz cuadrada $A$ de orden $n\times n$:

  • Simétrica: $A^T = A \quad \implies \quad a_{ij} = a_{ji}$ para todo $i,j$.
  • Antisimétrica: $A^T = -A \quad \implies \quad a_{ij} = -a_{ji}$ para todo $i,j$ (y los elementos diagonales son cero $a_{ii} = 0$).

Descomposición Única $A = S + K$

Toda matriz cuadrada $A$ se puede descomponer de manera única en la suma de una matriz simétrica $S$ y una matriz antisimétrica $K$:

$$A = \underbrace{\frac{A + A^T}{2}}_{\text{Simétrica } S} + \underbrace{\frac{A - A^T}{2}}_{\text{Antisimétrica } K}$$
